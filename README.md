⚙️ Setup Steps

1. npm install

2. npx playwright install

Run tests:

🎭 Playwright
    Go to project root
    Run: npx playwright test tests/playwright.test.ts --headed   

🧪 CodeceptJS
Go to project root
Run: npx codeceptjs run tests/codeceptJS.test.ts
